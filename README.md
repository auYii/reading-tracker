# 📚 我的阅读记录

一个简洁的个人阅读记录网页，用来记录自己读过的小说，并统计每个月和每年的阅读字数。

## ✨ 功能

### 📖 小说记录

可以记录每本小说的详细信息：

- 小说名称
- 作者
- 主CP
- 副CP
- 阅读字数
- 开始阅读时间
- 完成时间
- 阅读状态
- 标签
- 个人评分
- 个人感受

### 📊 阅读统计

首页会自动统计当前年份的阅读情况：

- 年度阅读字数
- 本月阅读字数
- 年度完成小说数量
- 总小说数量

### 🗓️ 月度阅读格子

使用月份格子展示全年阅读情况。

- 12个月固定显示
- 每个月显示阅读字数
- 阅读字数越多，绿色越深
- 使用半透明柔和绿色
- 月份和阅读字数始终保持在格子中央
- 没有阅读记录的月份同样保持固定布局
- 不会因为字数变化导致文字位置跳动

### 🔍 搜索与排序

支持：

- 根据小说名称搜索
- 根据作者搜索
- 根据角色 / CP 搜索
- 根据标签搜索
- 按开始阅读时间排序
- 按阅读字数排序

### 📦 数据管理

阅读记录保存在浏览器本地，可以：

- 导出阅读记录 JSON
- 导入之前保存的 JSON
- 删除和编辑已有记录

## 🎨 页面设计

整体采用简洁、柔和的风格：

- 米白色背景
- 白色卡片
- 柔和绿色作为主要强调色
- 简洁的阅读统计区域
- 小说卡片支持展开和折叠

## 🛠️ 技术

本项目使用原生前端技术制作：

- HTML
- CSS
- JavaScript
- LocalStorage

不需要安装额外的前端框架，也不需要后端服务器。
